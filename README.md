# Portfolio Website

A modern, responsive portfolio website showcasing my projects, skills, and experience as a MERN Stack Developer.

## Features

- **Responsive Design** - Mobile-first approach with smooth animations
- **Dark Mode Support** - Toggle between light and dark themes
- **Smooth Scrolling** - Lenis smooth scroll integration
- **Interactive Animations** - GSAP and Framer Motion animations
- **Project Showcase** - Featured projects with detailed information
- **Downloadable CV** - One-click resume download
- **Contact Form** - Get in touch section with social links

## Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS, shadcn/ui components
- **Animations**: GSAP, Framer Motion, Lenis
- **Icons**: Lucide React, React Icons
- **Deployment**: Netlify/Vercel

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/Anzumul-Jubayer/portfolio.git
cd portfolio
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

## Build for Production

```bash
npm run build
```

The production-ready files will be in the `dist/` folder.

## Preview Production Build

```bash
npm run preview
```
